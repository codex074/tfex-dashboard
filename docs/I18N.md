# Internationalization (i18n)

## Supported languages

- `th` — Thai (default)
- `en` — English

## Library

`i18next` + `react-i18next`. Resources are split by namespace per domain (not
one monolithic file).

## File structure

```
apps/web/src/i18n/
├── index.ts                  # init, initial language, persistence
└── locales/
    ├── th/
    │   ├── common.json
    │   ├── dashboard.json
    │   ├── trades.json
    │   ├── journal.json
    │   ├── analytics.json
    │   ├── portfolio.json
    │   └── cashflow.json
    └── en/
        ├── common.json
        ├── dashboard.json
        ├── trades.json
        ├── journal.json
        ├── analytics.json
        ├── portfolio.json
        └── cashflow.json
```

## Naming conventions

- Namespace = domain (`common`, `dashboard`, `trades`, `journal`, `analytics`,
  `portfolio`, `cashflow`).
- Keys are nested, camelCase, grouped by feature:
  `trades.columns.averageEntry`.
- Trading data values (instrument codes, `LONG`/`SHORT`, statuses) are **not**
  translated; only their labels are.
- Some financial terms deliberately remain in English inside Thai labels for
  clarity (e.g. `กำไร/ขาดทุนที่รับรู้แล้ว (Realized P/L)`).

## Language persistence

Selection is stored in `localStorage` under `tfex.language`:

```text
Saved preference → Thai default
```

The language switches immediately without a page reload and persists across
navigation, refresh, and browser restart.

## Number formatting

Use `Intl.NumberFormat` with the active locale (`th-TH`, `en-US`). Thai and
English both present Baht as `฿52,996.20`.

## Date formatting

Use `Intl.DateTimeFormat` with the active locale:

- Thai: `15 สิงหาคม 2569`
- English: `15 August 2026`

Internally all dates are Gregorian `YYYY-MM-DD`. Buddhist Era years are never
stored in the database.

## Adding a translation key

1. Add the key to both `th/*.json` and `en/*.json` in the matching namespace.
2. Use it in a component via `useTranslation()` and `t("namespace.key")`.
3. Never hardcode user-facing strings in JSX.

## What must NOT be translated

- Contract codes (`S50U26`, `S50Z26`, `GOZ26`, `USDZ26`)
- Broker references, account numbers, transaction IDs, filenames
- Raw broker values
- Journal content (user-generated; Thai stays Thai, English stays English)
- Tags (user-generated)
